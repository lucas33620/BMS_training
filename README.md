# BMS Training

Host-based training project created to prepare for embedded BMS development.

The goal of this project is not to build a production-ready Battery Management System, but to practice the software concepts and tools commonly used in modular embedded firmware.

## Training Goals

This project will progressively cover:

* Embedded-oriented modern C++ 23
* Modular firmware architecture
* Interfaces and dependency injection
* CMake
* GoogleTest
* BMS fundamentals
* Fault management
* Basic diagnostic and UDS concepts

## Project Constraints

The project runs entirely on a PC.
Hardware-related components will be simulated through simple software modules and interfaces.

## Build

The build procedure will be added once the initial CMake configuration is introduced.
